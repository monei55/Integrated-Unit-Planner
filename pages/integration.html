Step 3

Integration

Identify the meaningful connections between selected learning areas. Integration should strengthen the learning rather than force subjects together or reduce individual curriculum demands.

Integration principle: Look for shared concepts, knowledge, vocabulary, processes or authentic products. Each learning area should still contribute purposeful learning and identifiable curriculum evidence.
