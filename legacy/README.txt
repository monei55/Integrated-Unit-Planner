Integrated Unit Planner — V3.4.7

Open index.html in Chrome or Edge.

New in v2.5:
- Achievement Standard aspects remain the only curriculum selections.
- Optional “View related V9 content descriptions” reference panels beneath curriculum aspects.
- Official AC9 content-description codes are shown as reference, not required selections.
- Every lesson card has a Curriculum reference button so teachers can consult relevant content while planning without leaving the learning sequence.
- Reference material is grouped using the same teacher-friendly curriculum areas as the Achievement Standard aspects.

Note: The current verified dataset contains English, Mathematics, Science, HASS and HPE. Remaining Technologies and Arts V9 datasets are still to be completed.

V2.6: Added Whole-School Plan driven term/year suggestions, editable curriculum package defaults, and print alignment summary.


Version 2.7 update:
- Added Years 5–6 Achievement Standard aspects for Dance, Drama, Media Arts, Music and Visual Arts from official ACARA wording supplied by the user.
- Arts aspects are explicitly organised into Knowledge & Understanding and Skills.


Version 3.2 update:
- Added official V9 Design and Technologies Achievement Standard aspects for Foundation, Years 1–2, Years 3–4 and Years 5–6.
- Added official V9 Digital Technologies Achievement Standard aspects for Foundation, Years 1–2, Years 3–4 and Years 5–6.
- Added Technologies content descriptions as optional curriculum-reference data, grouped by official strands/sub-strands.
- Curriculum metadata now records ACARA official V9 sources as the authoritative curriculum source.


V3.4.3 Assessment & GTMJ build
- Curriculum-to-assessment alignment by selected year level and Achievement Standard aspect
- Assessment title, technique, purpose, context, task/evidence and conditions
- Evidence-location mapping for every selected aspect
- Editable task-specific A-E GTMJ builder, with C anchored to the selected Achievement Standard wording
- Assessment accessibility and evidence-coverage prompts
- Assessment quality check
- Structured assessment and GTMJ content included in the printable unit overview

Important: A-E prompts are planning scaffolds only. Teachers should use current QCAA standard elaborations and school moderation processes when finalising task-specific descriptors.


V3.4.3 changes:
- Build assessment evidence one year level at a time for multi-age units.
- Option to reuse the previous year level task structure without carrying across its standards.
- Already-mapped aspects are hidden from later primary lists by default.
- Previously used aspects remain available through integration opportunities or Show already-used aspects.
- Add another question/task component button appears at the bottom of every component.
- Evidence analysis is year-level specific.

V3.4.4 fix: assessment year selector is now driven by Unit Setup year levels, so teachers explicitly choose the first cohort before assessment content renders.


V3.4.6 fix:
- Assessment year dropdown is now present in the base HTML so its change event is always available.
- Assessment-year choices recover from visible Unit Setup year chips, application state, or exact selected year-level standards.
- Changing year levels in Unit Setup immediately refreshes the assessment-year dropdown.
- Assessment content remains blank until a year level is deliberately chosen.


V3.4.7 refinements:
- Moved Build draft assessment to the bottom of the Assessment Evidence Map to reduce scrolling.
- Added Suggest question wording within each evidence-map component.
- Potential questions use the selected year-level Achievement Standard aspects, cognitive demand, selected evidence format and assessment context as editable starting points.
